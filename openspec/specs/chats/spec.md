# chats

## Purpose

Возможность описывает работу **Текущего пользователя** со своими **Чатами**:
как он видит их список, создает новый **Чат**, выбирает один из них и
добавляет в него **Участников чата**. Переписка сюда не входит.

## Requirements

### Requirement: Список чатов

Приложение SHALL показывать **Текущему пользователю** список его **Чатов**
сразу после открытия экрана и SHALL брать состав списка у внешнего API, а не
собирать его локально.

После неудавшейся загрузки приложение SHALL давать **Текущему пользователю**
повторить запрос, не перезагружая страницу.

Для каждого **Чата** список SHALL показывать **Аватар**, название, последнее
сообщение и число непрочитанных сообщений. Число непрочитанных - значение из
ответа внешнего API; приложение его не вычисляет и не меняет.

#### Scenario: У текущего пользователя есть чаты

- **WHEN** **Текущий пользователь** открывает экран чатов
- **THEN** он видит список своих **Чатов**
- **AND** каждая строка показывает **Аватар**, название, последнее сообщение и
  число непрочитанных

#### Scenario: У чата нет последнего сообщения

- **WHEN** внешнее API не вернуло последнее сообщение **Чата**
- **THEN** строка показывает название и **Аватар**
- **AND** на месте последнего сообщения показывается «Сообщений пока нет»

#### Scenario: Чатов еще нет

- **WHEN** внешнее API вернуло пустой список
- **THEN** вместо списка показывается объяснение, что **Чатов** пока нет
- **AND** остается доступным создание **Чата**

#### Scenario: Список не загрузился

- **WHEN** запрос списка **Чатов** завершился ошибкой
- **THEN** показывается **Ошибка приложения**
- **AND** список не подменяется состоянием «Чатов еще нет»

#### Scenario: Повторная загрузка после ошибки

- **WHEN** запрос списка **Чатов** завершился ошибкой
- **AND** **Текущий пользователь** просит повторить загрузку
- **THEN** список запрашивается заново
- **AND** при успехе **Ошибка приложения** сменяется списком **Чатов**

### Requirement: Создание чата

**Текущий пользователь** SHALL создавать **Чат**, указав его название.
Подтвердить создание SHALL быть нельзя, пока название не указано: кнопка
создания остается недоступной. Приложение SHALL перезапрашивать список
**Чатов** после успешного создания и SHALL не собирать строку нового **Чата**
из данных формы. Сообщение об обязательности названия SHALL показываться под
полем после ухода с него, а не при открытии формы. Поле названия SHALL быть
недоступно, пока идет создание. **Ошибка приложения** при создании SHALL
показываться **Уведомлением**, а не текстом в форме.

#### Scenario: Чат создан

- **WHEN** **Текущий пользователь** указывает название и подтверждает создание
- **AND** внешнее API отвечает успехом
- **THEN** форма создания закрывается
- **AND** новый **Чат** появляется в списке

#### Scenario: Название не указано

- **WHEN** название пустое
- **THEN** кнопка создания недоступна, и подтвердить создание нельзя

#### Scenario: Название стерли после ввода

- **WHEN** **Текущий пользователь** ввел название, а затем очистил поле
- **THEN** кнопка создания снова становится недоступной

#### Scenario: Ошибка обязательности появляется после ухода с поля

- **WHEN** **Текущий пользователь** открыл форму создания и поля не трогал
- **THEN** под полем названия нет сообщения об ошибке, а кнопка создания недоступна

#### Scenario: Ошибка обязательности показана под полем

- **WHEN** **Текущий пользователь** перевел фокус в поле названия и увел его, оставив поле пустым
- **THEN** под полем показывается сообщение об обязательности, а кнопка создания остается недоступной

#### Scenario: Форма заблокирована во время создания

- **WHEN** запрос на создание **Чата** выполняется
- **THEN** поле названия и кнопка создания недоступны до получения ответа

#### Scenario: Создание отклонено

- **WHEN** внешнее API отвечает ошибкой
- **THEN** форма остается открытой с введенным названием
- **AND** показывается **Уведомление** об ошибке с текстом **Ошибки приложения**

#### Scenario: Сообщение об ошибке не остается в форме

- **WHEN** создание **Чата** отклонено
- **THEN** форма не содержит текста **Ошибки приложения**
- **AND** **Уведомление** видно поверх модального окна с формой

#### Scenario: Закрытие формы на успехе не ломает интерфейс

- **WHEN** успех отправки закрывает форму
- **THEN** **Уведомление** об исходе показывается на своем обычном месте, а остальной интерфейс продолжает обновляться

### Requirement: Выбранный чат

Приложение SHALL определять **Выбранный чат** адресом страницы, а не
состоянием экрана, и SHALL показывать рядом со списком его шапку: **Аватар**,
название и **Участников чата**.

#### Scenario: Чат выбран

- **WHEN** **Текущий пользователь** выбирает **Чат** в списке
- **THEN** адрес страницы указывает на этот **Чат**
- **AND** рядом со списком показывается его шапка

#### Scenario: Возврат по адресу выбранного чата

- **WHEN** **Текущий пользователь** открывает адрес **Выбранного чата** заново
- **THEN** тот же **Чат** снова выбран

#### Scenario: Шапка ждет чат

- **WHEN** **Выбранный чат** открыт до того, как список **Чатов** загружен
- **THEN** шапка не показывается, пока **Чат** не найдется в списке

#### Scenario: Чат не выбран

- **WHEN** адрес страницы не указывает ни на один **Чат**
- **THEN** вместо шапки показывается объяснение, что **Чат** не выбран

#### Scenario: Выбранного чата не существует

- **WHEN** адрес указывает на **Чат**, которого нет у **Текущего пользователя**
- **THEN** показывается **Ошибка приложения**
- **AND** список **Чатов** остается доступным

### Requirement: Участники выбранного чата

Шапка **Выбранного чата** SHALL показывать его **Участников чата**. Когда их
больше, чем помещается, шапка SHALL показывать часть **Аватаров** и число
остальных. Нажатие на **Аватары** и число остальных SHALL открывать и закрывать
весь состав **Чата** рядом с перепиской **Выбранного чата**, не перекрывая ее;
это доступно каждому **Участнику чата**, а не только **Создателю чата**.
Открытый состав SHALL закрываться только явно - повторным нажатием на
**Аватары** или кнопкой закрытия в самом составе.

Шапка SHALL показывать состав только по последнему запросу состава: ответ и
ошибка по более раннему запросу MUST NOT показываться, даже если пришли позже.

#### Scenario: Участники помещаются

- **WHEN** **Участников чата** не больше, чем помещается в шапке
- **THEN** показаны **Аватары** всех

#### Scenario: Участников больше, чем помещается

- **WHEN** **Участников чата** больше, чем помещается в шапке
- **THEN** показана часть **Аватаров** и число остальных

#### Scenario: Чат сменили до ответа

- **WHEN** **Текущий пользователь** выбирает другой **Чат**, пока состав
  прежнего не загрузился
- **AND** состав прежнего **Чата** приходит позже состава выбранного
- **THEN** шапка показывает состав выбранного **Чата**
- **AND** состав прежнего **Чата** его не подменяет

#### Scenario: Прежний чат ответил ошибкой после смены

- **WHEN** **Текущий пользователь** выбирает другой **Чат**, пока состав
  прежнего не загрузился
- **AND** загрузка состава прежнего **Чата** завершается ошибкой
- **THEN** **Ошибка приложения** не показывается
- **AND** показывает состав выбранного **Чата**

#### Scenario: Состав загружается после ошибки

- **WHEN** состав одного **Чата** не загрузился
- **AND** **Текущий пользователь** выбирает другой **Чат**
- **THEN** шапка показывает состав выбранного **Чата**

#### Scenario: Состав открыт

- **WHEN** **Участник чата** нажимает на **Аватары** в шапке
- **THEN** рядом с перепиской показан весь состав **Чата**: **Аватар** и имя каждого **Участника чата** и их общее число
- **AND** строка **Текущего пользователя** помечена как его собственная

#### Scenario: Состав не помещается

- **WHEN** **Участников чата** больше, чем помещается в открытом составе
- **THEN** список **Участников чата** прокручивается внутри состава, а заголовок с их числом остается на месте

#### Scenario: Состав закрыт повторным нажатием

- **WHEN** состав **Чата** открыт и **Участник чата** снова нажимает на **Аватары** в шапке
- **THEN** состав **Чата** закрывается

#### Scenario: Состав закрыт кнопкой закрытия

- **WHEN** состав **Чата** открыт и **Участник чата** нажимает в нем кнопку закрытия
- **THEN** состав **Чата** закрывается

#### Scenario: Переход к другому чату

- **WHEN** состав **Чата** открыт и **Текущий пользователь** выбирает другой **Чат**
- **THEN** состав остается открытым и показывает **Участников чата** нового **Выбранного чата**

#### Scenario: Состав не загрузился

- **WHEN** состав **Чата** открыт, а **Участников чата** загрузить не удалось
- **THEN** вместо шапки, места под переписку и состава показывается **Ошибка приложения**

### Requirement: Поиск пользователя

**Текущий пользователь** SHALL искать **Пользователей** по началу их
**Логина**, находясь в **Выбранном чате**. Приложение SHALL отправлять запрос
по мере ввода и SHALL показывать результат последнего ввода, а не первого
пришедшего ответа.

Пустой результат поиска SHALL не быть **Ошибкой приложения**.

#### Scenario: Поиск не начат

- **WHEN** поле поиска пустое
- **THEN** показывается подсказка начать вводить **Логин**
- **AND** запрос не отправляется

#### Scenario: Пользователи найдены

- **WHEN** **Текущий пользователь** ввел начало **Логина**
- **THEN** показывается список найденных **Пользователей**

#### Scenario: Никого не нашли

- **WHEN** внешнее API вернуло пустой список
- **THEN** показывается сообщение, что никто не найден
- **AND** это состояние отличается от состояния «поиск не начат»

#### Scenario: Ввод продолжился до ответа

- **WHEN** **Текущий пользователь** продолжает ввод, пока предыдущий запрос не
  ответил
- **THEN** показывается результат последнего ввода
- **AND** ответ на предыдущий ввод результат не подменяет

### Requirement: Добавление участника

**Текущий пользователь** SHALL добавлять найденного **Пользователя** в
**Выбранный чат**. Приложение SHALL обновлять состав **Выбранного чата** после
успешного добавления. **Ошибка приложения** при добавлении SHALL показываться
**Уведомлением**, а не текстом в **Поиске пользователя**.

#### Scenario: Участник добавлен

- **WHEN** **Текущий пользователь** выбирает найденного **Пользователя**
- **AND** внешнее API отвечает успехом
- **THEN** поиск закрывается
- **AND** добавленный **Участник чата** виден в шапке **Выбранного чата**

#### Scenario: Добавление отклонено

- **WHEN** внешнее API отвечает ошибкой
- **THEN** поиск остается открытым с найденными **Пользователями**
- **AND** показывается **Уведомление** об ошибке с текстом **Ошибки приложения**

#### Scenario: Исход виден после закрытия поиска

- **WHEN** добавление отклонено, а **Текущий пользователь** уже закрыл **Поиск пользователя**
- **THEN** **Уведомление** об ошибке все равно показывается

#### Scenario: Закрытие поиска на успехе не ломает интерфейс

- **WHEN** успешное **Добавление участника** закрывает **Поиск пользователя**
- **THEN** **Уведомление** об исходе показывается на своем обычном месте, а остальной интерфейс продолжает обновляться

### Requirement: Удаление чата

**Создатель чата** SHALL иметь возможность удалить **Выбранный чат** из его
шапки. Действие MUST быть доступно только **Создателю чата**: остальным
**Участникам чата** оно не показывается. **Удаление чата** MUST требовать
подтверждения и MUST NOT выполняться до того, как человек согласился.

#### Scenario: Действие доступно создателю чата

- **WHEN** **Создатель чата** открывает **Выбранный чат**
- **THEN** в шапке рядом с добавлением участника видно действие удаления

#### Scenario: Действие названо для скринридера

- **WHEN** действие удаления показано значком без подписи
- **THEN** у него есть доступное имя, по которому понятно, что оно удаляет **Чат**

#### Scenario: Действие скрыто от остальных участников

- **WHEN** **Выбранный чат** открывает **Участник чата**, который его не заводил
- **THEN** действия удаления в шапке нет

#### Scenario: Автор чата еще неизвестен

- **WHEN** **Выбранный чат** открыт до того, как список **Чатов** загружен
- **THEN** действия удаления нет, а не показано на случай, если право подтвердится

#### Scenario: Подтверждение запрошено

- **WHEN** **Создатель чата** запускает **Удаление чата**
- **THEN** показывается подтверждение с названием **Чата** и предупреждением, что действие необратимо и снимет **Чат** у всех **Участников чата**

#### Scenario: Подтверждение отклонено

- **WHEN** человек отказывается в окне подтверждения
- **THEN** **Чат** остается в списке и остается **Выбранным чатом**, а внешнее API не вызывается

#### Scenario: Чат удален

- **WHEN** человек подтверждает **Удаление чата** и внешнее API отвечает успехом
- **THEN** окно подтверждения закрыто, удаленного **Чата** в списке больше нет, **Выбранного чата** нет, а об успехе сообщает **Уведомление**

#### Scenario: Удаление отклонено

- **WHEN** внешнее API отвечает отказом на **Удаление чата**
- **THEN** **Чат** остается в списке и остается **Выбранным чатом**, а текст **Ошибки приложения** показывается **Уведомлением**

#### Scenario: Исход виден после закрытия подтверждения

- **WHEN** окно подтверждения закрылось сразу после согласия, а ответ внешнего API пришел позже
- **THEN** исход **Удаления чата** все равно показывается **Уведомлением**

### Requirement: Исключение участника

**Создатель чата** SHALL иметь возможность исключить **Участника чата** из
**Выбранного чата**, находясь в открытом составе **Чата**. Действие MUST быть
доступно только **Создателю чата**: остальным **Участникам чата** оно не
показывается. Свою строку **Создатель чата** MUST NOT исключать.
**Исключение участника** MUST требовать подтверждения и MUST NOT выполняться
до того, как человек согласился. Исход SHALL сообщаться **Уведомлением**.

#### Scenario: Действие доступно создателю чата

- **WHEN** **Создатель чата** открывает состав **Выбранного чата**
- **THEN** у каждого **Участника чата**, кроме него самого, видно действие исключения, без наведения указателя

#### Scenario: Своей строки действие не касается

- **WHEN** **Создатель чата** открывает состав **Выбранного чата**
- **THEN** у его собственной строки действия исключения нет

#### Scenario: Действие названо для скринридера

- **WHEN** действие исключения показано значком без подписи
- **THEN** у него есть доступное имя, по которому понятно, кого оно исключает

#### Scenario: Действие скрыто от остальных участников

- **WHEN** состав **Выбранного чата** открывает **Участник чата**, который его не заводил
- **THEN** ни у одной строки действия исключения нет

#### Scenario: Автор чата еще неизвестен

- **WHEN** состав открыт до того, как список **Чатов** загружен
- **THEN** действия исключения нет ни у одной строки, а не показано на случай, если право подтвердится

#### Scenario: Подтверждение запрошено

- **WHEN** **Создатель чата** запускает **Исключение участника**
- **THEN** показывается подтверждение с именем **Участника чата** и названием **Чата**
- **AND** кнопка согласия не оформлена как опасное действие
- **AND** состав **Чата** под подтверждением остается открытым

#### Scenario: Подтверждение отклонено

- **WHEN** человек отказывается в окне подтверждения
- **THEN** состав **Чата** не меняется, внешнее API не вызывается, а состав **Чата** остается открытым

#### Scenario: Участник исключен

- **WHEN** человек подтверждает **Исключение участника** и внешнее API отвечает успехом
- **THEN** окно подтверждения закрыто, а исключенного **Участника чата** больше нет ни в открытом составе, ни в шапке **Выбранного чата**
- **AND** состав **Чата** остается открытым с новым числом **Участников чата**
- **AND** об успехе сообщает **Уведомление**

#### Scenario: Исключение отклонено

- **WHEN** внешнее API отвечает отказом на **Исключение участника**
- **THEN** состав **Чата** не меняется, а текст **Ошибки приложения** показывается **Уведомлением**

#### Scenario: Исход виден после закрытия состава

- **WHEN** человек закрыл состав **Чата** после согласия, а ответ внешнего API пришел позже
- **THEN** исход **Исключения участника** все равно показывается **Уведомлением**
