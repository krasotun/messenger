# chats

## Purpose

Возможность описывает работу **Текущего пользователя** со своими **Чатами**:
как он видит их список, создает новый **Чат**, выбирает один из них и
добавляет в него **Участников чата**. Переписка сюда не входит.

## Requirements

### Requirement: Список чатов

Приложение SHALL показывать **Текущему пользователю** список его **Чатов**
сразу после открытия экрана и SHALL брать состав списка у внешнего API, а не
собирать его локально.

После неудавшейся загрузки приложение SHALL давать **Текущему пользователю**
повторить запрос, не перезагружая страницу.

Для каждого **Чата** список SHALL показывать **Аватар**, название, последнее
сообщение и число непрочитанных сообщений. Число непрочитанных - значение из
ответа внешнего API; приложение его не вычисляет и не меняет.

#### Scenario: У текущего пользователя есть чаты

- **WHEN** **Текущий пользователь** открывает экран чатов
- **THEN** он видит список своих **Чатов**
- **AND** каждая строка показывает **Аватар**, название, последнее сообщение и
  число непрочитанных

#### Scenario: У чата нет последнего сообщения

- **WHEN** внешнее API не вернуло последнее сообщение **Чата**
- **THEN** строка показывает название и **Аватар**
- **AND** на месте последнего сообщения показывается «Сообщений пока нет»

#### Scenario: Чатов еще нет

- **WHEN** внешнее API вернуло пустой список
- **THEN** вместо списка показывается объяснение, что **Чатов** пока нет
- **AND** остается доступным создание **Чата**

#### Scenario: Список не загрузился

- **WHEN** запрос списка **Чатов** завершился ошибкой
- **THEN** показывается **Ошибка приложения**
- **AND** список не подменяется состоянием «Чатов еще нет»

#### Scenario: Повторная загрузка после ошибки

- **WHEN** запрос списка **Чатов** завершился ошибкой
- **AND** **Текущий пользователь** просит повторить загрузку
- **THEN** список запрашивается заново
- **AND** при успехе **Ошибка приложения** сменяется списком **Чатов**

### Requirement: Создание чата

**Текущий пользователь** SHALL создавать **Чат**, указав его название.
Приложение SHALL перезапрашивать список **Чатов** после успешного создания и
SHALL не собирать строку нового **Чата** из данных формы. **Ошибка
приложения** при создании SHALL показываться **Уведомлением**, а не текстом в
форме.

#### Scenario: Чат создан

- **WHEN** **Текущий пользователь** указывает название и подтверждает создание
- **AND** внешнее API отвечает успехом
- **THEN** форма создания закрывается
- **AND** новый **Чат** появляется в списке

#### Scenario: Название не указано

- **WHEN** название пустое
- **THEN** подтвердить создание нельзя

#### Scenario: Создание отклонено

- **WHEN** внешнее API отвечает ошибкой
- **THEN** форма остается открытой с введенным названием
- **AND** показывается **Уведомление** об ошибке с текстом **Ошибки приложения**

#### Scenario: Сообщение об ошибке не остается в форме

- **WHEN** создание **Чата** отклонено
- **THEN** форма не содержит текста **Ошибки приложения**
- **AND** **Уведомление** видно поверх модального окна с формой

#### Scenario: Закрытие формы на успехе не ломает интерфейс

- **WHEN** успех отправки закрывает форму
- **THEN** **Уведомление** об исходе показывается на своем обычном месте, а остальной интерфейс продолжает обновляться

### Requirement: Выбранный чат

Приложение SHALL определять **Выбранный чат** адресом страницы, а не
состоянием экрана, и SHALL показывать рядом со списком его шапку: **Аватар**,
название и **Участников чата**.

#### Scenario: Чат выбран

- **WHEN** **Текущий пользователь** выбирает **Чат** в списке
- **THEN** адрес страницы указывает на этот **Чат**
- **AND** рядом со списком показывается его шапка

#### Scenario: Возврат по адресу выбранного чата

- **WHEN** **Текущий пользователь** открывает адрес **Выбранного чата** заново
- **THEN** тот же **Чат** снова выбран

#### Scenario: Чат не выбран

- **WHEN** адрес страницы не указывает ни на один **Чат**
- **THEN** вместо шапки показывается объяснение, что **Чат** не выбран

#### Scenario: Выбранного чата не существует

- **WHEN** адрес указывает на **Чат**, которого нет у **Текущего пользователя**
- **THEN** показывается **Ошибка приложения**
- **AND** список **Чатов** остается доступным

### Requirement: Участники выбранного чата

Шапка **Выбранного чата** SHALL показывать его **Участников чата**. Когда их
больше, чем помещается, шапка SHALL показывать часть **Аватаров** и число
остальных. Это число SHALL не быть элементом управления: экрана состава
**Чата** в приложении нет.

#### Scenario: Участники помещаются

- **WHEN** **Участников чата** не больше, чем помещается в шапке
- **THEN** показаны **Аватары** всех

#### Scenario: Участников больше, чем помещается

- **WHEN** **Участников чата** больше, чем помещается в шапке
- **THEN** показана часть **Аватаров** и число остальных
- **AND** число остальных не реагирует на нажатие

### Requirement: Поиск пользователя

**Текущий пользователь** SHALL искать **Пользователей** по началу их
**Логина**, находясь в **Выбранном чате**. Приложение SHALL отправлять запрос
по мере ввода и SHALL показывать результат последнего ввода, а не первого
пришедшего ответа.

Пустой результат поиска SHALL не быть **Ошибкой приложения**.

#### Scenario: Поиск не начат

- **WHEN** поле поиска пустое
- **THEN** показывается подсказка начать вводить **Логин**
- **AND** запрос не отправляется

#### Scenario: Пользователи найдены

- **WHEN** **Текущий пользователь** ввел начало **Логина**
- **THEN** показывается список найденных **Пользователей**

#### Scenario: Никого не нашли

- **WHEN** внешнее API вернуло пустой список
- **THEN** показывается «Никого не нашли»
- **AND** это состояние отличается от состояния «поиск не начат»

#### Scenario: Ввод продолжился до ответа

- **WHEN** **Текущий пользователь** продолжает ввод, пока предыдущий запрос не
  ответил
- **THEN** показывается результат последнего ввода
- **AND** ответ на предыдущий ввод результат не подменяет

### Requirement: Добавление участника

**Текущий пользователь** SHALL добавлять найденного **Пользователя** в
**Выбранный чат**. Приложение SHALL обновлять состав **Выбранного чата** после
успешного добавления. **Ошибка приложения** при добавлении SHALL показываться
**Уведомлением**, а не текстом в **Поиске пользователя**.

#### Scenario: Участник добавлен

- **WHEN** **Текущий пользователь** выбирает найденного **Пользователя**
- **AND** внешнее API отвечает успехом
- **THEN** поиск закрывается
- **AND** добавленный **Участник чата** виден в шапке **Выбранного чата**

#### Scenario: Добавление отклонено

- **WHEN** внешнее API отвечает ошибкой
- **THEN** поиск остается открытым с найденными **Пользователями**
- **AND** показывается **Уведомление** об ошибке с текстом **Ошибки приложения**

#### Scenario: Исход виден после закрытия поиска

- **WHEN** добавление отклонено, а **Текущий пользователь** уже закрыл **Поиск пользователя**
- **THEN** **Уведомление** об ошибке все равно показывается

#### Scenario: Закрытие поиска на успехе не ломает интерфейс

- **WHEN** успешное **Добавление участника** закрывает **Поиск пользователя**
- **THEN** **Уведомление** об исходе показывается на своем обычном месте, а остальной интерфейс продолжает обновляться
