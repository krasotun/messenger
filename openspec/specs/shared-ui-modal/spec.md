# shared-ui-modal

## Purpose

Модальное окно как примитив общего UI: показывает произвольное содержимое
поверх приложения, удерживает клавиатурный фокус и сообщает наружу о закрытии.
Примитив не знает ни про один домен и ни про один экран.

## Requirements

### Requirement: Открытие модального окна с произвольным содержимым

Приложение SHALL уметь открыть модальное окно с произвольным компонентом в
качестве содержимого и передать этому компоненту входные данные. Модалка SHALL
располагаться по центру экрана поверх остального интерфейса.

#### Scenario: Модалка открыта

- **WHEN** вызывается открытие модалки с компонентом-содержимым
- **THEN** содержимое отображается в модальном окне по центру экрана, а остальная часть приложения затеняется

#### Scenario: Изменение размера окна браузера

- **WHEN** размер окна меняется при открытой модалке
- **THEN** модалка остается по центру экрана

#### Scenario: Блокировка прокрутки

- **WHEN** модалка открыта
- **THEN** вертикальная и горизонтальная прокрутка приложения заблокирована

#### Scenario: Восстановление прокрутки

- **WHEN** модалка закрывается
- **THEN** прокрутка приложения восстанавливается

### Requirement: Единое событие закрытия

Модалка SHALL закрываться по кнопке закрытия, по `Escape`, по клику на затемненный
фон и по сигналу из содержимого. Все источники MUST приводить к одному и тому же
событию закрытия: потребитель не различает, откуда пришло закрытие.

#### Scenario: Закрытие по кнопке

- **WHEN** пользователь нажимает кнопку закрытия
- **THEN** модалка закрывается и наружу отправляется событие закрытия

#### Scenario: Закрытие по Escape

- **WHEN** пользователь нажимает `Escape`
- **THEN** модалка закрывается и наружу отправляется событие закрытия

#### Scenario: Закрытие по клику на фон

- **WHEN** пользователь кликает по затемненному фону вокруг модалки
- **THEN** модалка закрывается и наружу отправляется событие закрытия

#### Scenario: Закрытие по сигналу из содержимого

- **WHEN** компонент-содержимое сообщает о необходимости закрыться
- **THEN** модалка закрывается и наружу отправляется событие закрытия

#### Scenario: Клик внутри модалки

- **WHEN** пользователь кликает внутри модального окна
- **THEN** модалка остается открытой и событие закрытия не отправляется

#### Scenario: Освобождение ресурсов

- **WHEN** модалка закрыта
- **THEN** overlay уничтожается

### Requirement: Внутренняя верстка модального окна

Модальное окно SHALL отделять содержимое от своих границ отступами. Кнопка
закрытия SHALL находиться в одном ряду с заголовком окна и MUST NOT
перекрывать содержимое.

#### Scenario: Отступы содержимого

- **WHEN** модалка открыта с произвольным содержимым
- **THEN** содержимое отделено отступами от краев окна

#### Scenario: Кнопка закрытия в ряду с заголовком

- **WHEN** модалка открыта с заданным заголовком
- **THEN** заголовок и кнопка закрытия находятся в одном ряду: заголовок у левого края, кнопка у правого

#### Scenario: Заголовок не задан

- **WHEN** модалка открывается без заголовка
- **THEN** окно показывает кнопку закрытия у правого края, а место под заголовок не занимает содержимое

### Requirement: Заголовок модального окна

Тот, кто открывает модалку, SHALL иметь возможность задать ее заголовок.
Заголовок SHALL быть необязательным. Заданный заголовок MUST объявляться
скринридером как имя окна.

#### Scenario: Заголовок задан при открытии

- **WHEN** модалка открывается с указанным заголовком
- **THEN** этот заголовок отображается в окне

#### Scenario: Имя окна для скринридера

- **WHEN** модалка открыта с заданным заголовком
- **THEN** окно объявляется как диалог с этим заголовком в качестве имени

### Requirement: Управление фокусом

Пока модалка открыта, клавиатурный фокус SHALL оставаться внутри нее. При
открытии фокус MUST перемещаться в модалку, при закрытии MUST возвращаться на
элемент, который был в фокусе до открытия.

#### Scenario: Фокус при открытии

- **WHEN** модалка открывается
- **THEN** фокус перемещается на первый доступный для фокуса элемент внутри модалки

#### Scenario: Tab не выводит фокус за пределы модалки

- **WHEN** фокус находится на последнем доступном элементе модалки и пользователь нажимает `Tab`
- **THEN** фокус переходит на первый элемент модалки, а не на интерфейс за ней

#### Scenario: Shift+Tab не выводит фокус за пределы модалки

- **WHEN** фокус находится на первом доступном элементе модалки и пользователь нажимает `Shift+Tab`
- **THEN** фокус переходит на последний элемент модалки, а не на интерфейс за ней

#### Scenario: Возврат фокуса при закрытии

- **WHEN** модалка закрывается любым из источников закрытия
- **THEN** фокус возвращается на элемент, который был в фокусе до ее открытия

### Requirement: Размеры модального окна

Модалка SHALL поддерживать три пресета ширины: `small`, `medium`, `large`.
Пресет по умолчанию - `medium`. Высота MUST определяться содержимым.

#### Scenario: Задан пресет размера

- **WHEN** модалка открывается с указанным пресетом
- **THEN** ширина модалки соответствует этому пресету

#### Scenario: Пресет не задан

- **WHEN** модалка открывается без указания пресета
- **THEN** используется ширина пресета `medium`

#### Scenario: Содержимое меняет высоту

- **WHEN** высота содержимого меняется при открытой модалке
- **THEN** высота модалки следует за высотой содержимого

### Requirement: Единственность активной модалки

Одновременно SHALL быть открыто не более одного модального окна.

#### Scenario: Повторное открытие при активной модалке

- **WHEN** открытие вызывается повторно, пока модалка уже открыта
- **THEN** вторая модалка не создается и уже открытая остается без изменений
