## REMOVED Requirements

### Requirement: Открытие модального окна с произвольным содержимым

**Reason**: Собственного модального окна в приложении больше нет: содержимое
открывается диалогом UI-кита, и его раскладку, затенение и блокировку
прокрутки задает кит.

**Migration**: Фича открывает содержимое диалогом кита напрямую. Сценарии
экранов, где окно появляется (`chats`: «Создание чата»; `identity-access`:
редактирование профиля и смена пароля), остаются в своих спеках.

### Requirement: Единое событие закрытия

**Reason**: Способы закрытия (кнопка, `Escape`, клик по фону, сигнал из
содержимого) дает диалог кита. Закрытие по завершенному переходу перестает
быть свойством окна.

**Migration**: Закрытие открытого окна при переходе закреплено сценарием
«Открытая форма закрывается» требования «Истечение сессии» в
`identity-access`; его обеспечивает подписка на завершенный переход в `core`.

### Requirement: Внутренняя верстка модального окна

**Reason**: Отступы, заголовок и место кнопки закрытия задает тема кита.

**Migration**: Не требуется; вид окна фиксируют эталоны `@visual`.

### Requirement: Заголовок модального окна

**Reason**: Заголовок - параметр диалога кита, кит же объявляет его именем
окна.

**Migration**: Открывающий передает заголовок диалогу кита.

### Requirement: Управление фокусом

**Reason**: Удержание и возврат фокуса дает диалог кита; своих требований к
фокусу проект не ведет.

**Migration**: Не требуется.

### Requirement: Размеры модального окна

**Reason**: Пресеты ширины `small`, `medium`, `large` были свойством
собственного окна. Ширину окна задает параметр диалога кита.

**Migration**: Все окна открываются с одной общей шириной из общих опций
открытия диалога; выбора из нескольких пресетов нет.

### Requirement: Единственность активной модалки

**Reason**: Кит допускает несколько диалогов одновременно. Затененный фон не
дает человеку открыть второе окно, а программного запрета приложение больше не
держит.

**Migration**: Не требуется. Код, который полагался на отказ в открытии,
удаляется вместе с собственным окном.

### Requirement: Ссылка на открытое окно

**Reason**: Ссылку на открытое окно выдает кит; случая «окно не открылось,
потому что другое уже открыто» больше нет.

**Migration**: Открывающий пользуется ссылкой, которую возвращает диалог кита.
