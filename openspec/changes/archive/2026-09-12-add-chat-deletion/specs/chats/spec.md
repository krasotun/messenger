## ADDED Requirements

### Requirement: Удаление чата

**Создатель чата** SHALL иметь возможность удалить **Выбранный чат** из его
шапки. Действие MUST быть доступно только **Создателю чата**: остальным
**Участникам чата** оно не показывается. **Удаление чата** MUST требовать
подтверждения и MUST NOT выполняться до того, как человек согласился.

#### Scenario: Действие доступно создателю чата

- **WHEN** **Создатель чата** открывает **Выбранный чат**
- **THEN** в шапке рядом с добавлением участника видно действие удаления

#### Scenario: Действие названо для скринридера

- **WHEN** действие удаления показано значком без подписи
- **THEN** у него есть доступное имя, по которому понятно, что оно удаляет **Чат**

#### Scenario: Действие скрыто от остальных участников

- **WHEN** **Выбранный чат** открывает **Участник чата**, который его не заводил
- **THEN** действия удаления в шапке нет

#### Scenario: Автор чата еще неизвестен

- **WHEN** шапка **Выбранного чата** показана до того, как список **Чатов** загружен
- **THEN** действия удаления нет, а не показано на случай, если право подтвердится

#### Scenario: Подтверждение запрошено

- **WHEN** **Создатель чата** запускает **Удаление чата**
- **THEN** показывается подтверждение с названием **Чата** и предупреждением, что действие необратимо и снимет **Чат** у всех **Участников чата**

#### Scenario: Подтверждение отклонено

- **WHEN** человек отказывается в окне подтверждения
- **THEN** **Чат** остается в списке и остается **Выбранным чатом**, а внешнее API не вызывается

#### Scenario: Чат удален

- **WHEN** человек подтверждает **Удаление чата** и внешнее API отвечает успехом
- **THEN** окно подтверждения закрыто, удаленного **Чата** в списке больше нет, **Выбранного чата** нет, а об успехе сообщает **Уведомление**

#### Scenario: Удаление отклонено

- **WHEN** внешнее API отвечает отказом на **Удаление чата**
- **THEN** **Чат** остается в списке и остается **Выбранным чатом**, а текст **Ошибки приложения** показывается **Уведомлением**

#### Scenario: Исход виден после закрытия подтверждения

- **WHEN** окно подтверждения закрылось сразу после согласия, а ответ внешнего API пришел позже
- **THEN** исход **Удаления чата** все равно показывается **Уведомлением**
