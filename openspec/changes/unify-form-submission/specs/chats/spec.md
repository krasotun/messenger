## MODIFIED Requirements

### Requirement: Создание чата

**Текущий пользователь** SHALL создавать **Чат**, указав его название.
Подтвердить создание SHALL быть нельзя, пока название не указано: кнопка
создания остается недоступной. Приложение SHALL перезапрашивать список
**Чатов** после успешного создания и SHALL не собирать строку нового **Чата**
из данных формы. Сообщение об обязательности названия SHALL показываться под
полем после ухода с него, а не при открытии формы. Поле названия SHALL быть
недоступно, пока идет создание. **Ошибка приложения** при создании SHALL
показываться **Уведомлением**, а не текстом в форме.

#### Scenario: Чат создан

- **WHEN** **Текущий пользователь** указывает название и подтверждает создание
- **AND** внешнее API отвечает успехом
- **THEN** форма создания закрывается
- **AND** новый **Чат** появляется в списке

#### Scenario: Название не указано

- **WHEN** название пустое
- **THEN** кнопка создания недоступна, и подтвердить создание нельзя

#### Scenario: Название стерли после ввода

- **WHEN** **Текущий пользователь** ввел название, а затем очистил поле
- **THEN** кнопка создания снова становится недоступной

#### Scenario: Ошибка обязательности появляется после ухода с поля

- **WHEN** **Текущий пользователь** открыл форму создания и поля не трогал
- **THEN** под полем названия нет сообщения об ошибке, а кнопка создания недоступна

#### Scenario: Ошибка обязательности показана под полем

- **WHEN** **Текущий пользователь** перевел фокус в поле названия и увел его, оставив поле пустым
- **THEN** под полем показывается сообщение об обязательности, а кнопка создания остается недоступной

#### Scenario: Форма заблокирована во время создания

- **WHEN** запрос на создание **Чата** выполняется
- **THEN** поле названия и кнопка создания недоступны до получения ответа

#### Scenario: Создание отклонено

- **WHEN** внешнее API отвечает ошибкой
- **THEN** форма остается открытой с введенным названием
- **AND** показывается **Уведомление** об ошибке с текстом **Ошибки приложения**

#### Scenario: Сообщение об ошибке не остается в форме

- **WHEN** создание **Чата** отклонено
- **THEN** форма не содержит текста **Ошибки приложения**
- **AND** **Уведомление** видно поверх модального окна с формой

#### Scenario: Закрытие формы на успехе не ломает интерфейс

- **WHEN** успех отправки закрывает форму
- **THEN** **Уведомление** об исходе показывается на своем обычном месте, а остальной интерфейс продолжает обновляться
