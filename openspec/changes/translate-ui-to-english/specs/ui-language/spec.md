## Purpose

Описывает **Язык интерфейса**: на каком языке приложение обращается к человеку -
и на экране, и через скринридер. Возможность одна на все домены, потому что
текст показывают и `chats`, и `identity-access`, и общий UI.

## ADDED Requirements

### Requirement: Язык интерфейса

Приложение SHALL показывать человеку тексты только на английском языке.
Правило MUST распространяться на все, что адресовано человеку: подписи и
подсказки, сообщения об ошибках и **Уведомления**, названия действий и
доступные имена элементов, которые читает скринридер.

Правило MUST NOT распространяться на текст, адресованный разработчику:
комментарии в коде, артефакты `openspec/`, `CONTEXT.md` и `docs/` остаются
русскими.

Приложение SHALL быть одноязычным: выбора языка у человека нет, и текст не
зависит от настроек браузера или системы.

#### Scenario: Видимый текст на английском

- **WHEN** человек открывает любой экран приложения
- **THEN** все тексты на нем - английские

#### Scenario: Доступное имя на английском

- **WHEN** элемент управления показан значком без подписи
- **THEN** его доступное имя - английское

#### Scenario: Текст ошибки от внешнего API

- **WHEN** показывается **Ошибка приложения** с текстом из ответа внешнего API
- **THEN** показывается текст, который прислало внешнее API, как есть
- **AND** приложение его не переводит и не подменяет

#### Scenario: Язык не выбирается

- **WHEN** человек открывает приложение с любыми языковыми настройками браузера
- **THEN** интерфейс показан на английском
- **AND** переключателя языка на экране нет
