## ADDED Requirements

### Requirement: Отказ от подтверждения без выбора

Окно подтверждения **Удаления чата** и **Исключения участника** SHALL
предлагать ровно два исхода: согласиться или отказаться. Закрытие окна без
нажатия на одну из двух кнопок MUST считаться отказом: действие MUST NOT
выполняться, а внешнее API MUST NOT вызываться.

#### Scenario: Окно удаления закрыто клавишей Escape

- **WHEN** **Создатель чата** запускает **Удаление чата** и нажимает `Escape` в окне подтверждения
- **THEN** окно закрыто, **Чат** остается в списке и остается **Выбранным чатом**, а внешнее API не вызывается

#### Scenario: Окно удаления закрыто кнопкой закрытия

- **WHEN** **Создатель чата** запускает **Удаление чата** и закрывает окно подтверждения его кнопкой закрытия
- **THEN** окно закрыто, **Чат** остается в списке, а внешнее API не вызывается

#### Scenario: Окно исключения закрыто без выбора

- **WHEN** **Создатель чата** запускает **Исключение участника** и закрывает окно подтверждения, не нажав ни одну из двух кнопок
- **THEN** **Участник чата** остается в составе **Чата**, а внешнее API не вызывается

#### Scenario: Повторный запрос после закрытия без выбора

- **WHEN** **Создатель чата** закрыл окно подтверждения без выбора и запускает то же действие снова
- **THEN** окно подтверждения показывается заново, а согласие в нем выполняет действие ровно один раз

### Requirement: Удаление чата оформлено как опасное действие

Кнопка согласия в окне подтверждения **Удаления чата** SHALL быть оформлена
цветом опасности, потому что действие необратимо. Кнопка согласия в окне
**Исключения участника** SHALL быть оформлена как обычное основное действие:
исключенного можно добавить снова. Смысл обеих кнопок MUST читаться из их
подписи без опоры на цвет.

#### Scenario: Кнопка удаления чата

- **WHEN** показано окно подтверждения **Удаления чата**
- **THEN** кнопка согласия подписана `Delete` и оформлена цветом опасности

#### Scenario: Кнопка исключения участника

- **WHEN** показано окно подтверждения **Исключения участника**
- **THEN** кнопка согласия подписана `Remove` и оформлена как обычное основное действие
