## Why

Экранам нужен способ показать произвольный UI поверх приложения: ближайший
потребитель - редактирование профиля. Сейчас в `shared/ui/modal` лежит только
заглушка `ModalService.open()`, которая бросает `Not implemented`. Нужен
переиспользуемый примитив, который не знает ни про один домен.

Требования перенесены из `docs/features/shared-modal.md` (файл удаляется, его
содержимое становится этим change).

## What Changes

- Добавляется `ModalService` с методом открытия модального окна с произвольным
  компонентом-содержимым.
- Добавляется shell-компонент модалки: центрирование, затенение фона, блокировка
  скролла, всегда видимая кнопка закрытия.
- Добавляется `ModalRef` - способ для содержимого закрыть модалку изнутри.
  Результат наружу модалка не отдает.
- Модалка удерживает клавиатурный фокус внутри себя, пока открыта, и возвращает
  его на прежний элемент при закрытии.
- Вводятся три пресета ширины: `small`, `medium`, `large`; по умолчанию
  `medium`. Высота всегда определяется содержимым.
- Одновременно активна не более одной модалки: повторный `open()` при открытой
  модалке игнорируется.

## Capabilities

### New Capabilities

- `shared-ui-modal`: наблюдаемое поведение модального окна как примитива
  общего UI - открытие с произвольным содержимым, единое событие закрытия
  независимо от источника, удержание и возврат фокуса, размеры, единственность.

### Modified Capabilities

Нет.

## Impact

- Слои: только `shared/ui` (`src/app/shared/ui/modal`). Домены, `core` и `pages`
  не затрагиваются: примитив не должен знать про identity, profile и чаты.
- Зависимости: Angular CDK Overlay, уже в проекте.
- Тесты: component specs на поведение модалки; e2e не требуются - пользовательского
  сценария поверх примитива пока нет.
- Открывает дорогу change `update-profile`, которому нужна модалка для формы.
