## 1. Контракт примитива

- [ ] 1.1 Написать падающий spec: `open()` с компонентом-содержимым отображает его содержимое в модалке
- [ ] 1.2 Реализовать `ModalService.open()` поверх CDK Overlay и shell-компонент вместо текущей заглушки
- [ ] 1.3 Написать падающий spec на `ModalRef`, получаемый содержимым через DI
- [ ] 1.4 Реализовать `ModalRef` с `close()` и `save(data)`

## 2. Поведение окна

- [ ] 2.1 Spec: при открытой модалке фон затенен, а прокрутка приложения заблокирована
- [ ] 2.2 Spec: после закрытия прокрутка восстанавливается
- [ ] 2.3 Spec: модалка остается по центру при изменении размера окна
- [ ] 2.4 Реализовать центрирование, backdrop и блокировку скролла

## 3. Закрытие

- [ ] 3.1 Spec на каждый источник закрытия: кнопка, `Escape`, клик по backdrop, сигнал из содержимого - все дают одно событие закрытия
- [ ] 3.2 Spec: клик внутри модалки не закрывает ее
- [ ] 3.3 Spec: после закрытия overlay уничтожается
- [ ] 3.4 Реализовать обработку закрытия и освобождение overlay

## 4. Сохранение

- [ ] 4.1 Spec: `save(data)` из содержимого доставляет данные наружу и не смешивается с событием закрытия
- [ ] 4.2 Реализовать проброс данных сохранения

## 5. Размеры

- [ ] 5.1 Spec: заданный пресет задает ширину; без пресета применяется `medium`

- [ ] 5.3 Реализовать пресеты `small` / `medium` / `large`
