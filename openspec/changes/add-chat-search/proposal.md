## Why

Список **Чатов** растет, и найти нужный глазами становится дорого. Внешнее API
умеет подбирать **Чаты** по названию на своей стороне (`GET /chats?title=`), а
в приложении способа добраться до **Чата** по названию пока нет.

Issue: #95

## What Changes

- В панели списка **Чатов** между шапкой и списком появляется поле **Поиска
  чата**. Оно видно, только когда список загружен и не пуст.
- По мере ввода приложение спрашивает внешнее API о **Чатах** с таким
  названием и показывает найденные в выпадающем списке под полем: **Аватар** и
  название. Показывается ответ на последний ввод.
- В названиях найденных **Чатов** выделены все вхождения текста, по которому
  они найдены, без учета регистра. Выделяет общая директива из `shared/ui`.
- Ничего не нашлось или API отказало - выпадающий список говорит, что **Чатов**
  не найдено. Это не **Ошибка приложения** и не **Уведомление**.
- Выбор найденного **Чата** делает его **Выбранным чатом**: адрес страницы
  указывает на него, выпадающий список закрывается, поле очищается.
- Выпадающий список - это `Popover` из `shared/ui` в новом ручном режиме:
  его открывает и закрывает поиск, а не щелчок по полю. Escape и щелчок вне
  поля и списка закрывают его, введенный текст остается.
- Основной список **Чатов** и шапка **Выбранного чата** от поиска не зависят:
  список не сужается.
- `mock-backend` начинает понимать параметр `title` в `GET /chats`.

Вне объема: вступление в чужие **Чаты** (API их не находит), пагинация
списка **Чатов** (`limit`/`offset` в контракте необязательны и без значений по
умолчанию), выбор найденного **Чата** с клавиатуры - как и у **Поиска
пользователя**, выбор идет щелчком.

## Capabilities

### New Capabilities

- `shared-ui-text-highlight`: выделение вхождений строки в тексте как
  примитив общего UI.
- `shared-ui-popover`: всплывающая панель как примитив общего UI. Своей спеки
  у `Popover` не было; change описывает его текущее поведение и добавляет
  ручное открытие.

### Modified Capabilities

- `chats`: добавляется требование **Поиск чата**.

## Impact

- **application** (`src/app/domains/chats/application`): запрос **Чатов** по
  названию в `ChatGateway`, сервис и состояние **Поиска чата**.
- **infrastructure** (`src/app/domains/chats/infrastructure`): параметр
  `title` в `ChatApi.chats` и `HttpChatGateway.chats`.
- **presentation** (`src/app/domains/chats/presentation`): новый компонент
  поиска, встроенный в `chat-list`.
- **shared/ui** (`src/app/shared/ui`): директива выделения совпадений и ее
  глобальные стили; ручной режим в `popover/popover.ts` (режим по щелчку
  остается по умолчанию, `selected-chat-header` не меняется); в `src/styles.scss` - токен фона выделения и `@use`
  стилей директивы.
- **domain**, **core**: не затрагиваются.
- `mock-backend/src/routes/chats.ts`: фильтрация по `title`.
- e2e: сквозной сценарий поиска и скриншот выпадающего списка; канвас экрана
  чатов получает артборды поиска.
- Термин **Поиск чата** уже в `CONTEXT.md` (PR #200 в ветку issue).
