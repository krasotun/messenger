## ADDED Requirements

### Requirement: Поиск чата

**Текущий пользователь** SHALL находить свои **Чаты** по названию из панели
списка **Чатов**, чтобы один из найденных стал **Выбранным чатом**. Приложение
SHALL отправлять запрос по мере ввода, SHALL брать найденные **Чаты** у
внешнего API, а не подбирать их локально, и SHALL показывать результат
последнего ввода, а не первого пришедшего ответа.

Найденные **Чаты** SHALL показываться в выпадающем списке под полем
**Поиска чата**: **Аватар** и название каждого. В названии SHALL быть
выделены все вхождения текста, по которому показанные **Чаты** найдены, без
учета регистра. Основной список **Чатов** MUST NOT меняться от **Поиска
чата**.

Пустой результат **Поиска чата** SHALL не быть **Ошибкой приложения**. Отказ
внешнего API SHALL показываться так же, как пустой результат, и MUST NOT
показываться **Уведомлением**.

Поле **Поиска чата** SHALL быть видно, только когда список **Чатов** загружен и
не пуст.

#### Scenario: Поле поиска видно рядом со списком

- **WHEN** список **Чатов** загружен и в нем есть хотя бы один **Чат**
- **THEN** между шапкой панели и списком видно поле **Поиска чата**
- **AND** у поля есть доступное имя, по которому понятно, что оно ищет **Чаты**

#### Scenario: Поля поиска нет, пока искать нечего

- **WHEN** показано объяснение, что **Чатов** пока нет, или список **Чатов** не загрузился
- **THEN** поля **Поиска чата** нет

#### Scenario: Поиск не начат

- **WHEN** поле **Поиска чата** пустое
- **THEN** выпадающего списка нет
- **AND** запрос не отправляется

#### Scenario: Чаты найдены

- **WHEN** **Текущий пользователь** ввел текст в поле **Поиска чата**
- **AND** внешнее API вернуло **Чаты** для этого текста
- **THEN** под полем открывается выпадающий список с **Аватаром** и названием каждого из них

#### Scenario: Совпадение выделено

- **WHEN** выпадающий список показывает **Чаты**, найденные по тексту `back`
- **THEN** в названии `Backend backlog` выделены оба вхождения, `Back` и `back`

#### Scenario: Выделение следует показанному ответу

- **WHEN** **Текущий пользователь** продолжил ввод, а ответ на новый текст еще не пришел
- **THEN** выделение в показанных **Чатах** соответствует тексту, по которому они найдены, а не текущему содержимому поля

#### Scenario: Совпадения в названии нет

- **WHEN** внешнее API вернуло **Чат**, в названии которого введенный текст не встречается
- **THEN** его название показано без выделения

#### Scenario: Основной список не сужается

- **WHEN** выпадающий список **Поиска чата** показывает найденные **Чаты**
- **THEN** основной список **Чатов** показывает все **Чаты**, как до ввода

#### Scenario: Ничего не найдено

- **WHEN** внешнее API вернуло пустой список для введенного текста
- **THEN** выпадающий список сообщает, что **Чатов** не найдено

#### Scenario: Отказ внешнего API

- **WHEN** запрос **Поиска чата** завершился ошибкой
- **THEN** выпадающий список сообщает, что **Чатов** не найдено
- **AND** **Уведомление** не показывается
- **AND** следующий ввод снова отправляет запрос

#### Scenario: Ввод продолжился до ответа

- **WHEN** **Текущий пользователь** продолжает ввод, пока предыдущий запрос не ответил
- **THEN** показывается результат последнего ввода
- **AND** ответ на предыдущий ввод результат не подменяет

#### Scenario: Поле очищено

- **WHEN** **Текущий пользователь** стер весь текст в поле **Поиска чата**
- **THEN** выпадающий список закрывается

#### Scenario: Найденный чат выбран

- **WHEN** **Текущий пользователь** выбирает **Чат** в выпадающем списке
- **THEN** адрес страницы указывает на этот **Чат**, и он становится **Выбранным чатом**
- **AND** выпадающий список закрыт, а поле **Поиска чата** пустое

#### Scenario: Закрытие по Escape

- **WHEN** выпадающий список открыт и **Текущий пользователь** нажимает Escape
- **THEN** выпадающий список закрывается, а введенный текст остается в поле
- **AND** продолжение ввода открывает его снова

#### Scenario: Закрытие по щелчку вне

- **WHEN** выпадающий список открыт и **Текущий пользователь** щелкает вне поля **Поиска чата** и выпадающего списка
- **THEN** выпадающий список закрывается, а введенный текст остается в поле

#### Scenario: Щелчок в поле не закрывает список

- **WHEN** выпадающий список открыт и **Текущий пользователь** щелкает в поле **Поиска чата**
- **THEN** выпадающий список остается открытым
