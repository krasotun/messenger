## ADDED Requirements

### Requirement: Оверлеи под модалкой

Щелчок внутри модального окна MUST NOT закрывать всплывающие панели, открытые
под ним: для них это не щелчок «снаружи». `Escape` при открытой модалке SHALL
закрывать только модалку. Щелчок по затемненному фону SHALL закрывать модалку
и считаться щелчком «снаружи» для панелей под ней.

#### Scenario: Щелчок внутри модалки над панелью

- **WHEN** модалка открыта поверх всплывающей панели и пользователь щелкает внутри модального окна
- **THEN** всплывающая панель под модалкой остается открытой

#### Scenario: Escape над панелью

- **WHEN** модалка открыта поверх всплывающей панели и пользователь нажимает `Escape`
- **THEN** модалка закрывается, а всплывающая панель остается открытой

#### Scenario: Щелчок по фону над панелью

- **WHEN** модалка открыта поверх всплывающей панели и пользователь щелкает по затемненному фону
- **THEN** закрываются и модалка, и всплывающая панель
