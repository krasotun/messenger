## Why

**Текущий пользователь** создает **Чаты**, но убрать созданный **Чат** ему
нечем: список только растет, и ошибочно созданный **Чат** остается навсегда.
Внешнее API дает `DELETE /chats`, доступный **Создателю чата**.

**Удаление чата** необратимо и затрагивает всех **Участников чата**, поэтому
требует подтверждения. Подтверждать сейчас нечем: `ModalService.open()`
возвращает `void`, а требование «Единое событие закрытия» намеренно скрывает,
чем закончилась модалка. Общий примитив подтверждения нужен до самого
удаления.

Issue: #109

## What Changes

- В `shared/ui` появляется общий примитив подтверждения: он задает вопрос,
  различает подтверждение и отказ и умеет держать окно открытым, пока идет
  действие, показывая его ошибку.
- В шапке **Выбранного чата** появляется **Удаление чата**, видимое только
  **Создателю чата**.
- Модель **Чата** получает **Создателя чата**: поле `created_by` внешнее API
  отдает, а приложение его отбрасывает.
- После успешного **Удаления чата** список **Чатов** перезапрашивается, а
  адрес страницы перестает указывать на удаленный **Чат**.
- Мок-бэкенд учится удалять **Чат** и отдавать `created_by`: сейчас этого
  поля в его ответе нет, и действие не показалось бы ни человеку, ни e2e.

## Capabilities

### New Capabilities

Новых возможностей нет.

### Modified Capabilities

- `shared-ui-modal`: примитив учится задавать вопрос с подтверждением -
  различать подтверждение и отказ, вести действие подтверждения и показывать
  его ошибку, не закрываясь.
- `chats`: добавляется **Удаление чата**, видимое только **Создателю
  чата**.

## Impact

Слои: `shared` (новый примитив подтверждения), `application` (use case
удаления, контракт **Шлюза**, **Создатель чата** в модели **Чата**),
`infrastructure` (`DELETE /chats`, `created_by` в DTO и маппере),
`presentation` (шапка **Выбранного чата**). `core` не затрагивается.

Внешнее API: `DELETE /chats` (тело `{ chatId }`), `GET /chats` (поле
`created_by` начинает читаться). Поле объявлено в примерах `swagger.json`, но
отсутствует в `properties` схемы `ChatsResponse`; наличие проверено запросом к
боевому API 2026-09-05.

Прочее: `mock-backend` (удаление **Чата**, `created_by` в ответе), новый
скриншотный e2e на окно подтверждения.
