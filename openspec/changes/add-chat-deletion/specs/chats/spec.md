## ADDED Requirements

### Requirement: Удаление чата

**Текущий пользователь** SHALL выполнять **Удаление чата** для **Выбранного
чата**. Действие SHALL быть доступно только его **Создателю чата**; остальным
приложение MUST NOT показывать действие вовсе.

**Удаление чата** необратимо, поэтому приложение SHALL спрашивать
подтверждение и называть в вопросе **Чат**, который будет удален.

Действие SHALL быть показано значком без подписи и в этом случае MUST иметь
доступное имя, называющее удаление **Чата**.

После успешного **Удаления чата** приложение SHALL перезапрашивать список
**Чатов** у внешнего API и SHALL не оставлять адрес страницы указывающим на
удаленный **Чат**.

#### Scenario: Чат создан текущим пользователем

- **WHEN** **Текущий пользователь** открыл **Чат**, где он - **Создатель
  чата**
- **THEN** в шапке **Выбранного чата** доступно **Удаление чата**

#### Scenario: Чат создан другим пользователем

- **WHEN** **Текущий пользователь** открыл **Чат**, созданный не им
- **THEN** **Удаление чата** в шапке отсутствует

#### Scenario: Действие показано без подписи

- **WHEN** **Удаление чата** доступно **Текущему пользователю**
- **THEN** оно показано значком без видимой подписи
- **AND** у него есть доступное имя, называющее удаление **Чата**

#### Scenario: Подтверждение отклонено

- **WHEN** **Текущий пользователь** начинает **Удаление чата** и отказывается
  в вопросе подтверждения
- **THEN** **Чат** остается в списке
- **AND** **Выбранный чат** не меняется

#### Scenario: Чат удален

- **WHEN** **Текущий пользователь** подтверждает **Удаление чата**
- **AND** внешнее API отвечает успехом
- **THEN** список **Чатов** запрашивается заново и больше не содержит этот
  **Чат**
- **AND** адрес страницы больше не указывает на удаленный **Чат**
- **AND** вместо шапки показывается объяснение, что **Чат** не выбран

#### Scenario: Удаление отклонено

- **WHEN** **Текущий пользователь** подтверждает **Удаление чата**
- **AND** внешнее API отвечает ошибкой
- **THEN** вопрос подтверждения остается открытым и показывает **Ошибку
  приложения**
- **AND** **Чат** остается в списке
