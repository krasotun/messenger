## MODIFIED Requirements

### Requirement: Единое событие закрытия

Модалка SHALL закрываться по кнопке закрытия, по `Escape`, по клику на затемненный
фон и по сигналу из содержимого. Все источники MUST приводить к одному и тому же
событию закрытия: потребитель не различает, откуда пришло закрытие. Содержимое
SHALL иметь возможность приложить к закрытию результат; закрытие из любого
другого источника MUST приходить без результата.

#### Scenario: Закрытие по кнопке

- **WHEN** пользователь нажимает кнопку закрытия
- **THEN** модалка закрывается и наружу отправляется событие закрытия

#### Scenario: Закрытие по Escape

- **WHEN** пользователь нажимает `Escape`
- **THEN** модалка закрывается и наружу отправляется событие закрытия

#### Scenario: Закрытие по клику на фон

- **WHEN** пользователь кликает по затемненному фону вокруг модалки
- **THEN** модалка закрывается и наружу отправляется событие закрытия

#### Scenario: Закрытие по сигналу из содержимого

- **WHEN** компонент-содержимое сообщает о необходимости закрыться
- **THEN** модалка закрывается и наружу отправляется событие закрытия

#### Scenario: Закрытие с результатом от содержимого

- **WHEN** компонент-содержимое закрывает модалку и прикладывает результат
- **THEN** этот результат приходит вместе с событием закрытия

#### Scenario: Закрытие без результата

- **WHEN** модалка закрывается по кнопке закрытия, по `Escape` или по клику на фон
- **THEN** событие закрытия приходит без результата

#### Scenario: Клик внутри модалки

- **WHEN** пользователь кликает внутри модального окна
- **THEN** модалка остается открытой и событие закрытия не отправляется

#### Scenario: Освобождение ресурсов

- **WHEN** модалка закрыта
- **THEN** overlay уничтожается

## ADDED Requirements

### Requirement: Ссылка на открытое окно

Открывающий модалку SHALL получать ссылку на открытое окно, чтобы узнать о его
закрытии и прочитать результат. Если модалка не открылась, потому что другая уже
открыта, ссылка MUST NOT выдаваться.

#### Scenario: Модалка открыта

- **WHEN** открытие модалки вызвано при отсутствии других открытых окон
- **THEN** открывающий получает ссылку на открытое окно

#### Scenario: Модалка не открылась

- **WHEN** открытие вызвано, пока другая модалка уже открыта
- **THEN** открывающий не получает ссылки и понимает, что окно не открылось

#### Scenario: Открывающий узнает о закрытии

- **WHEN** открытая модалка закрывается любым из источников
- **THEN** открывающий узнает об этом по своей ссылке ровно один раз
