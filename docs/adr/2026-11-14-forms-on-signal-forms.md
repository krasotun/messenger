# Формы пишутся на Signal Forms

- Дата: 2026-11-14
- Статус: accepted

## Контекст

Формы жили на Reactive Forms, а остальное состояние приложения - на сигналах.
На стыке копилась обвязка: подписки на `control.events`, перекладывающие
состояние поля в сигнал, эффект, блокирующий форму на время отправки, ручной
`updateValueAndValidity` для правила, связывающего два поля. В Angular 21
появились Signal Forms, но весь их API помечен `@experimental`.

## Решение

Все формы и одиночные поля ввода пишутся на `@angular/forms/signals`;
Reactive Forms в `src` не остается.

## Причины

- Состояние поля - уже сигнал: `FormField`, `Input` и `Form` читают
  `touched()`, `errors()`, `valid()`, `dirty()` напрямую. Хелперы
  `createControlState` и `createSubmitAvailability` и отложенная
  инициализация в `ngOnInit` стали не нужны.
- Правила декларативны: недоступность полей на время отправки - правило
  `disabled` в схеме, сравнение пароля с повтором - `validate` с `valueOf`.
  Пересчет зависимого поля делает граф сигналов, а не подписка.
- Правила поля переиспользуются схемой (`emailSchema`, `phoneSchema`), а не
  копированием массива валидаторов из формы в форму.
- Один способ работать с полями: исключений для «простых» полей нет, поле
  поиска тоже на `[formField]`.

Чем пожертвовали:

- API экспериментальный: минорное обновление Angular может его сломать.
  Страхуют спеки форм - они написаны через DOM и не знают, на чем форма
  сделана; при этой миграции они прошли без правок.
- `FormRoot` и `submit()` не используем: они помечают все поля тронутыми при
  отправке невалидной формы, а у нас сообщение о нарушении появляется только
  после ухода с поля. `Form` слушает `submit` сам и сам ставит `novalidate`.
- `form()` читает модель при создании, поэтому модель нельзя вывести из
  обязательного `input` через `linkedSignal`: форма профиля заполняется
  эффектом.
- `[formField]` переносит правила схемы в нативные атрибуты `input`: `name`,
  `required`, `minlength`, `maxlength`. Нативный `maxlength` обрезает ввод
  раньше, чем человек увидит сообщение о нарушении, поэтому верхняя граница
  длины задается через `validate` с `maxLengthError`, а не через `maxLength`.

Отклонены:

- Остаться на Reactive Forms до стабилизации Signal Forms: обвязка между
  формами и сигналами продолжала бы расти с каждой новой формой, а зависимые
  поля - ближайшая задача форм - на ней пишутся подписками.
- Смешанный режим через `compatForm` и `SignalFormControl`: два способа
  описать поле в одном проекте, а форм всего пять - перевести их целиком
  дешевле, чем поддерживать мост.
